## 🎯 当前开发任务

### 🔥 专业术语库系统（当前第一优先级）

- **进度**: 20% 开发中
- **开始时间**: 2026-04-11
- **预计工期**: 2周（约80小时）
- **文档**: [PRD](特性开发/search-optimization-glossary/search-optimization-glossary-01-prd.md)

**核心功能**：
- 建立**多术语库集合系统**，支持用户自定义领域术语库（医疗、法律、IT等）
- 术语管理：添加、编辑、删除术语，支持同义词配置
- 查询扩展：根据选择的术语库扩展查询词，提升搜索召回率
- 术语库选择：在搜索设置中选择默认使用的术语库
- CSV导入/导出：支持导入外部术语库（行业标准术语）
- 预置术语库：系统启动时自动初始化常用术语库（IT、产品、医疗、法律）

**技术实现**：
- 数据库：新增 `glossary_collections` 和 `glossary_terms` 表
- 后端：新增 `GlossaryService` 术语匹配服务
- API：新增10个术语管理接口
- 前端：新增术语库管理页面（三栏布局）
- 搜索集成：修改搜索服务，集成术语扩展逻辑

**开发步骤**:

### ✅ 飞书数据源插件（已完成）

- **进度**: 100% 已完成
- **完成时间**: 2026-03-31
- **发布版本**: v1.7.0
- **文档**: [PRD](特性开发/plugins+feishu/plugins+feishu-01-prd.md)

**核心功能**：
- 自动识别从飞书导出的 Markdown 文档
- 解析飞书导出文档末尾的元数据块
- 提取原文链接和更新时间
- 搜索结果显示紫色"飞书"标识
- 支持一键跳转到飞书原文

**配套工具**：
- 飞书导出 CLI 工具（xiaoyaosearch-feishu-export）
- 支持单个文档、知识库、批量导出
- 自动下载图片和附件
- 增量导出功能

**技术实现**：
- 插件化架构：Python ABC + importlib
- 元数据解析：正则表达式匹配
- 数据源标识：source_type=feishu

### ✅ 语雀数据源插件（已完成）

- **进度**: 100% 已完成
- **完成时间**: 2026-02-24
- **发布版本**: v1.2.0
- **文档**: [PRD](特性开发/plugins+yuque/plugins+yuque-01-prd.md)

**核心功能**：
- 基于yuque-dl CLI工具实现语雀文档同步
- 支持增量下载、断点续传
- 搜索结果支持源链接跳转
- 显示"语雀"数据源标签

**技术实现**：
- 插件化架构：Python ABC + importlib
- 数据同步：yuque-dl CLI工具集成
- 元数据提取：原文链接和文档ID识别
- 异步架构：基于asyncio高性能处理
