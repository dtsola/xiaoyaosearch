## 1. 接口概述

### 基本信息
- **接口版本**: v3.6.0
- **基础URL**: `http://127.0.0.1:8000`
- **认证方式**: 本地应用，无需认证
- **数据格式**: JSON
- **字符编码**: UTF-8
- **插件支持**: 数据源插件（filesystem/yuque/feishu等）
- **元数据提供方式**: 插件通过 `get_file_source_info()` 方法提供数据源信息
- **术语库支持**: 专业术语库系统（v3.6.0新增）✨

### 交互式文档
- **Swagger UI**: `http://127.0.0.1:8000/docs`
- **ReDoc**: `http://127.0.0.1:8000/redoc`

### 技术栈
- **后端框架**: FastAPI + Uvicorn
- **数据验证**: Pydantic v2
- **异步支持**: asyncio
- **CORS**: 支持Electron跨域访问

## 2. 认证和错误处理

### 认证机制
```http
# 本地应用无需认证，支持Electron渲染进程访问
Origin: http://localhost:3000
```

### 统一错误响应格式
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "请求参数验证失败",
    "details": "query字段不能为空"
  }
}
```

### 国际化错误响应 ✅
为了支持多语言前端，API 错误响应采用错误码设计，前端根据错误码映射到对应语言的翻译：

**错误码响应格式**：
```json
{
  "success": false,
  "error": {
    "code": "index_not_found",
    "message": "索引不存在"
  }
}
```

**前端翻译映射**：
- 后端返回标准化的错误码（如 `index_not_found`）
- 前端 HTTP 拦截器根据错误码查找对应语言的翻译
- 支持中英文双语切换，用户看到的是其选择语言的错误提示

**支持的错误码类型**：
- HTTP 状态码映射：`bad_request`, `unauthorized`, `forbidden`, `not_found`, `internalServerError` 等
- 业务错误码：`index_not_found`, `model_load_failed`, `file_too_large` 等
- 详细的错误码列表请参考 [第12节 - 错误码参考](#12-错误码参考)

### HTTP状态码规范
| 状态码 | 说明 | 使用场景 |
|--------|------|----------|
| 200 | 成功 | 请求处理成功 |
| 400 | 请求错误 | 参数验证失败、格式错误 |
| 404 | 资源不存在 | 索引任务、模型配置不存在 |
| 413 | 文件过大 | 上传文件超过50MB限制 |
| 500 | 服务器错误 | 内部异常、AI模型加载失败 |

## 3. 数据模型

### 4.2 多模态搜索
```http
POST /api/search/multimodal
Content-Type: multipart/form-data
```

**表单参数**
- `input_type`: 输入类型 (voice/image)
- `file`: 上传的文件 (最大50MB)
- `search_type`: 搜索类型 (semantic/fulltext/hybrid)，默认hybrid
- `limit`: 返回结果数量 (1-100)，默认20
- `threshold`: 相似度阈值 (0.0-1.0)，默认0.7
- `file_types`: 文件类型过滤（可多选）

**支持的文件格式**
- **语音**: mp3, wav, m4a, flac (最大120秒)

## 5. 插件化架构与数据源配置（v3.0新增）

### 5.1 插件配置方式说明

插件化架构采用**约定优于配置**的设计理念，无需通过API管理插件：

**插件管理方式**：
- 插件无需通过API管理
- 插件放到 `data/plugins/` 目录自动加载
- 配置通过 `config.yaml` 文件完成
- 系统启动时自动同步数据源

### 5.2 插件目录结构（v3.3更新）

```
data/plugins/
├── datasource/           # 数据源插件目录
│   ├── yuque/           # 语雀知识库插件
│   │   ├── plugin.py    # 插件实现代码
│   │   ├── config.yaml  # 插件配置文件
│   │   └── data/        # 下载的数据目录
│   │       └── downloaded/
│   └── feishu/          # 飞书文档插件（未来）
│       ├── plugin.py
│       ├── config.yaml
│       └── data/
└── ai_model/            # AI模型插件目录（架构预留）
```

### 5.3 配置文件格式（v3.3更新）

**语雀插件配置示例** (`data/plugins/datasource/yuque/config.yaml`)

```yaml
# 插件基本信息
plugin:
  id: yuque
  name: 语雀知识库
  version: "1.0.0"
  type: datasource
  enabled: true

# 知识库配置列表（支持多个知识库）
repos:
  # 知识库 1：产品文档
  - name: "产品文档"
    url: "https://www.yuque.com/your-org/product-docs"
    download_dir: "./data/product-docs"
    token: ""  # 可选，私有知识库需要
    cookie_key: "_yuque_session"  # 可选，企业部署
    ignore_images: false
    incremental: true

  # 知识库 2：技术文档
  - name: "技术文档"
    url: "https://www.yuque.com/your-org/tech-docs"
    download_dir: "./data/tech-docs"
    token: ""
    ignore_images: false
    incremental: true
```

### 5.4 配置项说明（v3.3更新）

**插件基本信息**

| 配置项 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| plugin.id | string | 是 | 插件唯一标识 |
| plugin.name | string | 是 | 插件显示名称 |
| plugin.version | string | 是 | 版本号（semver格式） |
| plugin.type | string | 是 | 插件类型（datasource/ai_model等） |
| plugin.enabled | boolean | 是 | 是否启用插件 |

**知识库配置（repos 列表项）**

| 配置项 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 知识库名称（用于标识） |
| url | string | 是 | 语雀知识库 URL |
| download_dir | string | 是 | 下载目录（相对于插件目录） |
| token | string | 否 | 语雀 Cookie（私有知识库需要） |
| cookie_key | string | 否 | 企业部署的 Cookie Key（默认 `_yuque_session`） |
| ignore_images | boolean | 否 | 是否忽略图片（默认 false） |
| incremental | boolean | 否 | 是否增量下载（默认 true） |

### 5.5 配置文件加载流程（v3.3更新）

```
系统启动
    ↓
扫描 data/plugins/ 目录
    ↓
发现插件目录（datasource/yuque/、datasource/feishu/等）
    ↓
读取每个插件的 config.yaml
    ↓
验证配置有效性（检查 plugin.enabled）
    ↓
加载插件模块（plugin.py）
    ↓
初始化插件实例（调用 initialize()）
    ↓
自动执行插件同步（调用 sync()）
    ↓
同步完成，等待索引构建
```

**关键说明**：
- 插件自动发现：放到 `data/plugins/datasource/` 下自动加载
- 启动时同步：应用启动时自动执行增量同步
- 无需 API：不需要通过 API 手动触发同步

- 清空索引文件后，为每个历史已完成的索引任务创建新的重建任务
- 利用现有的 `run_full_index_task` 和 `IndexJobModel`
- 通过 BackgroundTasks 自动排队执行
- 复用现有的 `GET /api/index/status/{id}` 查询进度

**响应字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| index_id | integer | 索引任务ID |

**使用流程**：

2. 用户前往索引管理页，点击"全量重建索引"按钮
3. 前端调用此接口，后端清空索引并创建重建任务
4. 前端使用现有的 `GET /api/index/status/{index_id}` 轮询进度
5. 所有任务完成后显示成功提示

async function pollIndexProgress(indexId) {
  try {
    const response = await fetch(`/api/realtime/index/${indexId}/progress`);
    const result = await response.json();

    if (result.success) {
      const { data } = result;
      console.log(`索引进度: ${data.progress}%`);
      console.log(`已处理: ${data.processed_files}/${data.total_files}`);

      // 如果任务完成，停止轮询
      if (data.is_completed) {
        clearInterval(pollingInterval);
        console.log('索引任务已完成');

    }
  } catch (error) {
    console.error('获取进度失败:', error);
  }
}

// api/search.ts
import api from './config';

export interface SearchParams {
  query: string;
  input_type?: 'text' | 'voice' | 'image';
  search_type?: 'semantic' | 'fulltext' | 'hybrid';
  limit?: number;
  threshold?: number;
  file_types?: string[];
}

export class SearchService {
  // 文本搜索
  static async search(params: SearchParams) {
    return await api.post('/api/search', params);
  }

  // 多模态搜索
  static async multimodalSearch(
    inputType: 'voice' | 'image',
    file: File,
    searchType?: string,
    limit?: number,
    threshold?: number,
    fileTypes?: string[]
  ) {
    const formData = new FormData();
    formData.append('input_type', inputType);
    formData.append('file', file);

    if (searchType) {
      formData.append('search_type', searchType);
    }
    if (limit) {
      formData.append('limit', limit.toString());
    }
    if (threshold) {
      formData.append('threshold', threshold.toString());
    }
    if (fileTypes && fileTypes.length > 0) {
      fileTypes.forEach(fileType => {
        formData.append('file_types', fileType);
      });
    }

    return await api.post('/api/search/multimodal', formData, {
      headers: {
        'Content-Type': 'multipart/form-data'
      }
    });
  }

  // 搜索历史
  static async getHistory(limit = 20, offset = 0) {
    return await api.get(`/api/search/history?limit=${limit}&offset=${offset}`);
  }
}
