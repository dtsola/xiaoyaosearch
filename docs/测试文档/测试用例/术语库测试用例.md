# 术语库系统测试用例

> **测试范围**：专业术语库系统完整功能测试
> **创建时间**：2026-04-12
> **测试环境**：Windows 11 + Python 3.10 + Node.js 21

---

## 测试准备

### 环境启动

**1. 启动后端服务**
```bash
cd backend
python main.py
```
验证：访问 http://127.0.0.1:8000/docs 可访问

**2. 启动前端**
```bash
cd frontend
npm run electron:dev
```
