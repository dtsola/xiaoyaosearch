## 1. 设计理念

### 1.1 设计原则
- **领域隔离清晰**：不同领域的术语库有明确的视觉区分
- **管理操作便捷**：三栏布局，清晰的信息层级
- **选择控制灵活**：搜索设置中快速切换术语库
- **导入导出友好**：CSV格式模板下载，降低使用门槛

### 1.2 设计风格
- **卡片式术语库展示**：每个术语库采用独立卡片，左侧色条区分领域
- **图标化视觉语言**：使用Emoji图标增强领域识别（🏥医疗、⚖️法律、💻IT）
- **状态反馈明确**：启用/禁用状态清晰的视觉反馈
- **三栏主从结构**：术语库列表 → 术语列表 → 术语详情

## 2. 整体布局架构

### 2.1 入口设计（顶部导航栏）

术语库管理功能的入口位于**顶部导航栏**，在"索引"和"帮助"之间：

```
┌──────────────────────────────────────────────────────────────────────┐
│  ◤小遥搜索◢ v2.0                                                [─][□][×] │
├──────────────────────────────────────────────────────────────────────┤
│  ◇ 首页 ◇ 设置 ◇ 索引 ◇ 术语库 ◇ 帮助    [🌐中文▼] [🔔2] [🌙] [🎨] [👤admin]  │
└──────────────────────────────────────────────────────────────────────┘
```

**导航说明**：
- **首页**：搜索主页面
- **设置**：系统设置（搜索、索引、AI模型、数据源配置）
- **索引**：索引管理（构建索引、查看索引状态）
- **术语库**：术语库管理（新增入口）← 点击进入三栏术语库管理页面
- **帮助**：帮助文档

**交互**：
- 点击"术语库"导航项 → 进入术语库管理三栏页面
- 当前页面时"术语库"显示为 `●术语库`，其他显示为 `◇`
