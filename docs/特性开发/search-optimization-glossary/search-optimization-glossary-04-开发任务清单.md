## 设计原则：渐进式实施 + 复用现有架构

本特性基于现有搜索服务架构，核心是：
- **复用现有数据库层**：SQLAlchemy ORM + SQLite
- **复用现有API层**：FastAPI + Pydantic
- **复用现有前端框架**：Vue 3 + Ant Design Vue
- **新增术语扩展逻辑**：集成到 ChunkSearchService

## 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 数据库迁移失败 | 阻塞后续开发 | 提前测试迁移脚本，准备回滚方案 |
| 术语匹配性能问题 | 搜索变慢 | 批量查询优化，添加数据库索引，使用缓存 |
| 前端组件复杂度高 | 开发周期延长 | 分阶段实施，先实现核心功能，后优化交互 |
| CSV导入容错性差 | 用户体验差 | 完善错误处理，详细错误提示，支持部分导入 |

## 注意事项

1. **向后兼容**：所有修改不破坏现有功能，术语扩展为可选功能
2. **性能优先**：术语匹配必须<50ms，搜索性能下降<20%
3. **数据安全**：预置术语库不可删除，只能禁用
4. **用户体验**：CSV导入失败不影响其他术语，显示详细错误信息
5. **国际化**：所有新增文本必须包含中英文翻译
