## 1. 特性概述

### 1.1 定位（一句话）
对小遥搜索v2.0里程碑版本进行全面的UI视觉系统升级，采用Notion温暖明亮设计风格，为知识工作者提供更加专业、舒适、高效的产品体验。

### 1.2 背景与动机

**用户痛点**：
- **痛点1**：现有UI设计缺乏统一的设计系统规范，视觉风格不一致
- **痛点2**：字体使用较为通用（Inter、系统字体），缺乏品牌辨识度
- **痛点3**：界面层次感不够清晰，信息密度和视觉舒适度需要优化
- **痛点4**：作为v2.0里程碑版本，需要通过UI升级传递产品成熟度和专业性的提升

**业务价值**：
- **品牌价值提升**：通过统一且独特的设计语言，建立更强的品牌辨识度
- **用户体验改善**：更清晰的视觉层次和更舒适的界面设计，提升用户满意度和留存率
- **竞争力增强**：在同类型桌面搜索产品中，通过精致的UI设计建立竞争优势
- **里程碑意义**：v2.0版本作为重要里程碑，UI升级是版本升级的重要组成部分

**技术必要性**：
- 建立完整的设计系统规范，为后续功能迭代提供设计基础
- 优化前端组件架构，提升代码可维护性
- 完善响应式设计，确保不同屏幕尺寸下的体验一致性

### 1.3 目标用户

**主要用户**：知识工作者、内容创作者、技术开发者

**使用场景**：
- 长时间使用桌面应用进行文件搜索和管理
- 需要清晰、舒适的界面来提高工作效率
- 对产品美学和设计品质有一定要求

### 1.4 与主版本的关系

**依赖关系**：
- 基于主PRD v1.9版本的所有现有功能
- UI升级不影响现有功能逻辑，仅涉及视觉层改进
- 与国际化功能（i18n）保持兼容

**影响范围**：
- 前端所有页面的视觉样式
- 设计系统规范（颜色、字体、间距、圆角、阴影）
- 组件库样式更新

## 5. 详细设计

### 5.1 前端设计

#### 页面变更
| 页面/组件 | 变更类型 | 变更内容 | 关键改动点 |
|----------|---------|---------|-----------|
| 主页面（搜索页） | 修改 | 全面视觉升级 | 布局、色彩、字体、间距、阴影 |
| 设置页面 | 修改 | 统一样式风格 | 表单组件、卡片样式 |
| 索引管理页面 | 修改 | 统一样式风格 | 列表、状态指示器 |
| 帮助页面 | 修改 | 统一样式风格 | 文字排版、链接样式 |
| 全局导航栏 | 修改 | 优化高度和交互 | 56px高度，悬停效果 |
| 搜索结果卡片 | 修改 | 增强视觉效果 | 多层阴影、圆角12px |
| 按钮组件 | 修改 | 自定义样式 | 圆角4px，悬停动画 |
| 输入框组件 | 修改 | 优化焦点状态 | 蓝色光晕效果 |

#### 交互设计

**新增交互**：
- 页面加载时的fadeInUp动画（200ms延迟）
- 卡片悬停时的阴影加深效果
- 按钮悬停时的scale变换（1.05倍）
- 输入框焦点时的蓝色光晕效果

**修改交互**：
- 优化多模态指示器的切换反馈
- 增强所有可点击元素的视觉反馈
- 统一hover状态的颜色变化

#### UI/UX变更

**布局变更**：
- 主内容区域最大宽度从无限制调整为1200px
- 搜索容器最大宽度调整为700px
- 增加组件间距，提升呼吸感

**样式变更**：

**色彩系统**：
```css
/* 背景色系 */
--bg-primary: #ffffff           /* 纯白主背景 */
--bg-secondary: #f6f5f4         /* 温暖白次要背景 */
--bg-tertiary: #f9f8f6          /* 浅灰背景 */
--bg-hover: rgba(0, 0, 0, 0.03) /* 悬停背景 */

/* 文字色系 */
--text-primary: rgba(0, 0, 0, 0.92)    /* 主要文字 */
--text-secondary: #615d59              /* 次要文字 */
--text-tertiary: #9a9590               /* 辅助文字 */
--text-muted: #b8b3ae                  /* 弱化文字 */

/* 品牌色系 */
--brand-blue: #0075de              /* Notion蓝 */
--brand-blue-hover: #005fb8        /* 悬停蓝 */
--brand-blue-light: #e8f4fd        /* 浅蓝背景 */
```

**字体系统**：
- **标题字体**：Work Sans（400, 500, 600, 700）
- **正文字体**：Nunito（400, 500, 600, 700, 800）
- **代码字体**：保持原有等宽字体

**间距系统**（8px基准）：
```css
--space-xs: 4px
--space-sm: 8px
--space-md: 12px
--space-lg: 16px
--space-xl: 20px
--space-2xl: 24px
--space-3xl: 32px
```

**圆角系统**：
```css
--radius-sm: 4px     /* 按钮 */
--radius-md: 6px     /* 小卡片 */
--radius-lg: 10px    /* 中卡片 */
--radius-xl: 12px    /* 大卡片 */
--radius-pill: 9999px /* 徽章 */
```

**阴影系统**：
```css
/* 卡片阴影 - 4层堆叠 */
--shadow-card:
  rgba(0, 0, 0, 0.02) 0px 2px 8px,
  rgba(0, 0, 0, 0.015) 0px 1px 4px,
  rgba(0, 0, 0, 0.01) 0px 0.5px 2px,
  rgba(0, 0, 0, 0.008) 0px 0.2px 1px;

/* 悬浮阴影 - 5层堆叠 */
--shadow-elevated:
  rgba(0, 0, 0, 0.03) 0px 4px 12px,
  rgba(0, 0, 0, 0.02) 0px 2px 6px,
  rgba(0, 0, 0, 0.015) 0px 1px 3px,
  rgba(0, 0, 0, 0.01) 0px 0.5px 1px,
  rgba(0, 0, 0, 0.008) 0px 0.2px 0.5px;
```

**图标/图片**：
- 保持现有emoji图标的使用方式
- 新增渐变背景纹理（CSS实现）

### 18.3 FAQ

**Q1: 为什么选择Notion风格作为参考？**
A: Notion是知识管理领域的标杆产品，其温暖明亮的设计风格非常适合小遥搜索的知识工作者目标用户。同时，Notion的设计清晰、专业，经得起长时间使用的考验。

**Q2: 为什么不采用暗色模式？**
A: v2.0.0版本聚焦于明亮主题的优化，确保设计质量。暗色模式需要额外的设计工作，计划在后续版本中考虑。

**Q3: 字体加载会不会影响性能？**
A: 字体通过Google Fonts CDN加载，大小约50KB每种，加载时间目标<500ms。同时会提供系统字体作为回退方案，确保在任何情况下都能正常显示。

**Q4: UI升级是否会影响现有功能？**
A: 不会。本次升级仅涉及视觉层，不改变任何功能逻辑。所有现有功能将保持正常运行。

**Q5: 如何确保设计的一致性？**
A: 通过建立完整的设计系统（design tokens），使用CSS变量统一管理所有设计元素，确保全局一致性。
