## 快速复制命令

在项目根目录执行以下命令复制图片：

```bash
# Windows PowerShell
Copy-Item "docs\产品文档\产品截图\*.png" "docs\运营文档\video-project-v2\public\images\"
Copy-Item "docs\产品文档\产品截图\*.jpg" "docs\运营文档\video-project-v2\public\images\"

# 或者从产品文档目录复制所有截图
Copy-Item "docs\产品文档\产品截图\*" "docs\运营文档\video-project-v2\public\images\"
```

## 图片格式要求

- **格式**：PNG 或 JPG
- **分辨率**：建议 1920x1080 或更高
- **命名**：必须与上表中的文件名完全一致

## 注意事项

1. 确保所有图片都已复制到 `public/images/` 目录
2. 图片文件名必须与代码中的引用完全一致
3. 如果图片缺失，视频渲染时会显示错误
