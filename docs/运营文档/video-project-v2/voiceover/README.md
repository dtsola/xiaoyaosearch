# 配音制作说明

本目录包含小遥搜索 v2.0.0 宣传片的配音制作文件。

## 文件说明

- `配音文本.txt` - 所有场景的配音文本
- `generate_voiceover.py` - Edge TTS 批量生成脚本
- `README.md` - 本文件

## 快速开始

### 方法一：使用 Edge TTS 批量生成（推荐）

1. **安装依赖**
   ```bash
   pip install edge-tts
   ```

2. **生成配音**
   ```bash
   python generate_voiceover.py
   ```

   默认使用女声"晓晓"，如需男声：
   ```bash
   python generate_voiceover.py --voice male
   ```

3. **输出位置**
   配音文件将保存到 `../public/audio/` 目录

### 方法二：在线微软 TTS

1. 访问 https://speech.microsoft.com/tts
2. 选择语音：
   - 女声：晓晓（zh-CN-XiaoxiaoNeural）- 推荐
   - 男声：云扬（zh-CN-YunyangNeural）
3. 设置语速：1.0x（正常）
4. 复制各场景文本，依次生成并下载
5. 按场景命名：scene1.mp3, scene2.mp3, etc.

### 方法三：Edge 浏览器朗读

1. 打开 Edge 浏览器
2. 访问任意网页
3. 右键 → "朗读此页面内容"
4. 点击语音设置 → 选择"晓晓"
5. 使用录音软件（如 Audacity）录制

## 音频参数要求

- **采样率**：44.1kHz 或 48kHz
- **比特率**：128kbps 或更高
- **格式**：MP3
- **声道**：单声道或立体声


## 提示

- 建议使用女声"晓晓"，语速自然，适合技术产品宣传
- 生成后建议试听每个场景，确认时长和语速是否合适
- 场景3被分解为多个音频文件，便于与画面精确同步
