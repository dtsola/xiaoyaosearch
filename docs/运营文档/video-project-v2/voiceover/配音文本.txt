## 生成配音说明

### 方法一：Edge TTS 批量生成（推荐）

1. 安装依赖：
   ```bash
   pip install edge-tts
   ```

2. 运行生成脚本：
   ```bash
   cd voiceover
   python generate_voiceover.py
   ```

3. 选择语音：
   - 女声：晓晓（zh-CN-XiaoxiaoNeural）- 自然、亲切
   - 男声：云扬（zh-CN-YunyangNeural）- 稳重、专业

### 方法二：在线微软 TTS

1. 访问：https://speech.microsoft.com/tts
2. 选择语音：晓晓或云扬
3. 语速：1.0x（正常）
4. 依次复制各场景文本生成音频
5. 下载并按场景命名

### 方法三：Edge 浏览器朗读

1. 打开 Edge 浏览器
2. 访问任意网页，右键 → "朗读此页面内容"
3. 使用录音软件（如 Audacity）录制

---

## 音频参数要求

- 采样率：44.1kHz 或 48kHz
- 比特率：128kbps
- 格式：MP3
- 声道：单声道或立体声
